# Thank You UI Extension

This extension displays the configured giveaway message on Shopify's Thank You page.

The checkout-page block moved to the `black-friday-cart` Theme App Extension so the giveaway can appear on the cart page of stores that don't support checkout-page UI extensions.

The extension targets `purchase.thank-you.block.render` and reads the app-owned `black_friday_checkout_config` shop metafield.
